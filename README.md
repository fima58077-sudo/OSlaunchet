# OS Launcher

Android-лаунчер (Android 8+), который меняет стиль главного экрана: iOS, macOS, tvOS, visionOS.

- свои установленные приложения, страницы, док
- зажми иконку: о приложении, удалить, добавить в док
- зажми пустое место: настройки лаунчера (стиль, подписи, точки, размер иконок)

## Сборка
1. Создай репозиторий на GitHub и загрузи все файлы (папку .github сохрани).
2. Actions -> Build APK -> Run workflow.
3. Скачай артефакт OSLauncher-apk, установи app-debug.apk.
4. Настройки Android -> Приложения по умолчанию -> Домашнее приложение -> OS Launcher.
